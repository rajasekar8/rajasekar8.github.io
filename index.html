Where I've been, what I build now

12+ years in enterprise infrastructure, most recently as a Principal Infrastructure & AIOps Architect at Cognizant. The work has consistently come back to the same problem: enterprise monitoring platforms — SolarWinds, Cisco DNAC, AppDynamics, ThousandEyes — are each individually powerful but disconnected from each other, so teams lose time during an incident switching between four browser tabs instead of looking in one place. Ops Bot exists because I got tired of that gap and built the console that should have shipped with the platforms in the first place.

That same instinct — build the tool instead of just operating whatever exists — is what led to Riyaan, a personal AI agent platform with real tool execution, sandboxed security controls, and browser automation, not just a chatbot wrapper. Currently open to Principal or Senior Architect roles in Infrastructure, AIOps, or Platform Engineering — ideally somewhere that still wants someone building the tooling, not just running what's already there.

Ops Bot — Enterprise Ops Platform

Ask me for a walkthrough ↗
What this is — and why it matters
A 25,000+ line PowerShell WinForms application that unifies SolarWinds, Cisco DNAC/Catalyst Center, AppDynamics, and ThousandEyes into a single intelligent operations console. Compiled to a zero-install .exe via PS2EXE — no deployment, no dependencies, runs on any Windows machine. Most ops teams switch between four separate browser tabs to see what this shows on one screen.
📡
SolarWinds Orion
SWIS REST API · SWQL · NCM
  • Full CMDB node lifecycle — add, retire, remove, manage/unmanage with bulk operations
  • Alert muting with configurable duration and reason tracking
  • Network Configuration Manager — download configs, visual diff, side-by-side compare of any two snapshots
  • Interface traffic charts — real-time bandwidth graphs using Windows DataVisualization
  • SolarWinds Health Check — node health scoring across the full estate
  • Custom SWQL with parameterised inputs; all calls via POST to handle complex NCM joins
🌐
Cisco DNAC / Catalyst Center
REST API · Token auth · Paginated
  • Paginated device inventory with token-based auth and auto-refresh
  • Access Point inventory with signal and association data
  • SolarWinds vs DNAC reconciliation — finds devices in SW not in DNAC and vice versa
  • CMDB vs DNAC three-way comparison: SW only / DNAC only / in both
  • DNAC vs SW AP reconciliation — wireless estate alignment
  • All results exported to timestamped CSV for audit trail
⚡
AppDynamics SaaS
REST API · OAuth2 · APM estate
  • Application and tier listing across full APM estate
  • Performance metrics — response time, error rate, calls/min with configurable windows
  • Agent version audit — scans every App Agent and Machine Agent across all applications
  • Agent Upgrade Planner — auto-generates ready-to-action upgrade task list filtered by agent type
  • Token-based session management with login dialog and persistence
👁
ThousandEyes
v7 API · Agent inventory
  • Agent and test inventory across the TE estate
  • API key-based authentication with session persistence
  • Feeds into the Unified Alert Dashboard alongside SW and AppD

Advanced capabilities

🔗
Alert Correlation Engine
Groups active SW alerts by site code and time window. Automatically distinguishes site-wide events (multiple devices same location, same time) from individual node faults. Configurable threshold. Replicates what enterprise AIOps platforms charge separately for.
AIOps logic
📊
Unified Alert Dashboard
Aggregates live alerts from SolarWinds, AppDynamics, and ThousandEyes into a single view with shared time window selector (15 min → 48 hrs). Eliminates tool-switching during incidents.
Cross-platform
🕐
Maintenance Window Scheduler
Accepts CSV input or manual entry. Bot monitors the schedule and automatically mutes nodes at start time and unmutes at end — fully unattended maintenance window management without touching SolarWinds directly.
Automation
📋
Agent Upgrade Planner
Scans all AppDynamics APM applications across the estate, identifies App Agents and Machine Agents older than a target version, and outputs a ready-to-action upgrade task list — no manual spreadsheet needed.
Automation
📧
Email Notification Engine
Built-in SMTP with TLS support. Compose and send alert summaries or node reports directly from any panel. Programmatic mail dispatch for alerts and node events via dedicated invoke functions.
Ops workflow
💻
SSH Quick Terminal
Embedded SSH session launcher — connect to any node directly from inventory without switching tools. Reduces context switching during troubleshooting.
Ops workflow

Engineering decisions worth noting

DecisionWhy
WinForms + PS2EXESingle .exe, zero install, runs on any Windows machine — no runtime, no dependencies, no deployment
DPI via P/InvokePrevents text clipping at 125%/150% scaling without breaking PS2EXE compilation
All API calls via POSTAvoids 400 errors on complex SWQL with NCM joins that break GET requests at length
EST → UTC normalisationAll time inputs converted from EST to UTC before API calls — handles IST/GMT client machines transparently
Shared font objects at startupPrevents repeated GDI object allocation across 40+ panels — measurable memory impact at scale
TableLayoutPanel layout engineDeterministic pixel layout prevents control drift across different screen sizes and DPI settings
